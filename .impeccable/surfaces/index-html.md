# Surface brief: Athletics app shell (all screens)

Scope: the whole installed PWA (Aujourd'hui, Séances and session mode, Corps, Bilan and calendar, Réglages). Visitor mode: Operate. Audience: the owner, in the gym between sets, one hand, bright gym lighting; evening check-in at home. Constraint: every existing function, data format and test hook survives.

## Direction contract

THESIS: The gym's whiteboard, where the day's work is written up and struck off as it gets done. Refuses the category default of a near-black screen with one neon accent and progress rings.

OWN-WORLD: Clean white board ground, aluminium-grey tray surfaces, thin black tape rules; marker inks only: black for text and structure, blue for actions and selection, green for done, red only for alerts. Barlow for UI text, Barlow Condensed for big numbers (loads, reps, timer, weights). Square-ish 10px corners, no glow, no glass.

STORY: He opens the app, sees today's session and what is left, logs a set in one tap, watches it get struck off, and leaves.

FIRST VIEWPORT: Title and date at top; today's session block (name, exercises count, blue Démarrer) first; check-in rubriques below; tab bar at the bottom, black ink on white with a blue active tab.
